2. PRE-IMPLEMENTATION PROBLEM STATEMENT
================================================================================

The plan (implementation.txt) documented a “built but not working” gap chain:

  Symptom                          Evidence (pre-work)
  ─────────────────────────────────────────────────────────────────────────
  Empty personalization            memory.db: facts=0, corrections=0;
                                   user_model.db: um_facts=0, um_aliases=0
  WAL bloat                        memory.db ~4 KB but memory.db-wal ~2 MB
                                   with server stopped
  Verification hole                43/75 tools → classify_family() None →
                                   always UNKNOWN → cache never promotes
  Sparse tool metadata             Only 4/75 tools had verification= (UIA only,
                                   shape {"kind":"ui_state"}, not documented)
  Tiny cache                       command_cache: 6/500 entries; skills: 1
  Memory never fills               auto_capture() regex-only at chat_service
  No DB shutdown hygiene           No conn.close() / wal_checkpoint in startup
  Data dir grows forever           debug_logs, voice_cache, stale .bak, smoke
                                   JSON never pruned; no backups

Root cause chain (plan): UNKNOWN verdicts → promotion_policy rejects non-PASS
→ cache stays empty → every command runs full 16-step agent loop → slow; plus
assistant has no durable user model.
